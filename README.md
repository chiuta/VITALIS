## Features

- Nine evidence-ranked pillars with first moves and common pitfalls
- Event companion for BioHacking360 (unofficial)
- Calculators: HOMA-IR, TyG index, waist-to-height, Mifflin-St Jeor, heart-rate zones, sleep cycles, protein targets
- Fasting timer and breathing pacer
- 360 score with radar chart
- Biomarker reference ranges
- Daily ritual tracker, glossary and myths
- 8 languages, dark/light theme, JSON export/import, installable PWA

## Privacy

No tracking, no accounts, no network requests (CSP: connect-src none). Data stays in your browser's localStorage.

## Disclaimer

Educational only, not medical advice. Talk to your doctor before changing medication, diet or training. Unofficial companion based on public information from biohacking360.com.

## Run

Open index.html in any browser, or use the live app and install it as a PWA.
